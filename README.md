Clínica Veterinária - POO

Projeto desenvolvido em Python utilizando Programação Orientada a Objetos.

 Conceitos utilizados

- Classe Abstrata
- Herança
- Polimorfismo
- Encapsulamento
- Associação
- Listas

Funcionalidades

- Cadastro de tutores
- Cadastro de animais
- Consulta de animais
- Consulta de tutores
- Animais em atenção especial
- Protocolos de atendimento
